HOW TO USE CODEN607 SKILLS IN CHATGPT
======================================

CANONICAL SOURCE
https://github.com/coden607/skills

LIVE MODE (preferred when GitHub access is available)
1. Add bundle.md to the ChatGPT Project sources, or otherwise make it available
   to the Project.
2. Open Project settings and paste PROJECT-INSTRUCTIONS.md.
3. The router tells ChatGPT to inspect the canonical GitHub SKILL.md files
   lazily and load only the smallest relevant set.

OFFLINE / NO-GITHUB MODE
1. On a machine with the repository, run:
     python3 scripts/build-runtime-bundles.py --output-dir /tmp/coden607-chatgpt
2. Upload /tmp/coden607-chatgpt/coden607-skills-bundle.md to the Project or GPT
   Knowledge.
3. Also add bundle.md and use PROJECT-INSTRUCTIONS.md as the Project/GPT
   instructions.

PERMANENT CLI WIRING
Run:
  bash scripts/install-all-ai-skills.sh

That installs/synchronizes Claude, Codex and Grok native skill directories,
writes persistent Gemini/Kimi instruction adapters, and builds a local ChatGPT
bundle under ~/.coden607/chatgpt-bundle.

IMPORTANT
ChatGPT Projects can persist files and project instructions across chats in that
Project, but a VPS filesystem cannot silently replace a ChatGPT Project source.
When the canonical GitHub skills change and you rely on the offline bundle,
regenerate and replace that Project/GPT knowledge file.
